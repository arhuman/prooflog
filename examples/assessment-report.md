## 6. Upgrade path — from assessed to proven

This report is Tier 0. The assurance ladder:

- **Tier 0 — assessed (this report).** Analytical findings over an unsigned export.
- **Tier 1 — captured.** Record these events through a Prooflog agent: each is hashed, sequence-numbered, chained, and sealed. Sequence gaps become *provable*, not indicative.
- **Tier 2 — independently verified.** Run the verifier under a separate authority from the store operator; history cannot be rewritten undetectably.
- **Tier 3 — witnessed.** Add C2SP witness cosigning or a qualified timestamp anchor for external, legally-weighted attestation.

The gaps and blind spots this assessment could only flag as *indicative* become cryptographically provable at Tier 1 and above.
